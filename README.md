# CoatMath

Free paint calculator that tells you exactly which cans to buy: gallons needed, the cheapest mix of 5-gallon buckets, gallons and quarts, cost, leftover and a printable shopping list. Also wall, ceiling, exterior, primer and square footage calculators and a DIY vs pro paint cost estimator.

Live: https://matt5516.github.io/paint-calc/ (planned domain coatmath.com, not registered yet, pending the owner's approval)

Static HTML/CSS/JS, no backend, no ads, no cookies (cookieless GoatCounter visit counts only). Math lives in `assets/calc.js` (tested). Pages are generated by the shared build in Matt's sites workspace, so don't edit the HTML by hand. Estimates only: check your paint can's label for coverage.
